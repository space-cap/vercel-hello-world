GLOSSARY
핵심 기술 및 비즈니스 용어 사전
1인 창업과 바이브코딩 아키텍처 이해를 위한 개념 레퍼런스

가이드북 본문에서 자주 등장하는 창업 전략, 인프라, 보안 및 AI 개발 핵심 용어를 체계적으로 정리했습니다. 각 개념의 기술적 맥락과 실전 의미를 파악해 두면 7일 스프린트 개발 과정을 보다 명확하게 이해할 수 있습니다.

1. 비즈니스 및 제품 기획 (Business & Product)

MVP (Minimum Viable Product)

최소 기능 제품

아이디어의 시장 수요를 가장 적은 비용과 시간으로 검증하기 위해, 부가 기능을 배제하고 핵심 가치 1개만을 온전히 동작하도록 만든 제품입니다.

PMF (Product-Market Fit)

제품-시장 적합성

제공하는 제품이 타겟 시장의 절실한 문제와 일치하여, 인위적인 마케팅 없이도 유기적인 고객 유입과 지속적인 재결제가 발생하는 상태를 의미합니다.

SaaS (Software as a Service)

서비스형 소프트웨어

사용자 기기에 프로그램을 설치하지 않고, 웹 브라우저를 통해 클라우드 환경에서 서비스를 제공하며 정기 구독료 또는 사용량 기반으로 수익을 창출하는 모델입니다.

스프린트 (Sprint)

단기 개발 사이클

애자일 방법론의 핵심 실행 단위로, 7일 또는 14일과 같이 정해진 기간 동안 명확한 기능 범위를 집중 개발하여 배포 가능한 결과물을 만드는 작업 방식입니다.

2. 바이브코딩 및 AI 개발 (AI & Vibe Coding)

바이브 코딩 (Vibe Coding)

자연어 지시 기반 개발 패러다임

개별 프로그래밍 언어 문법을 직접 작성하는 대신, 만들고자 하는 기능의 명세와 아키텍처 맥락을 자연어로 AI에게 전달하여 코드를 생성하고 조율하는 방식입니다.

프롬프트 엔지니어링 (Prompt Engineering)

AI 지시 구조화 기법

AI 모델이 오류 없이 최적의 코드를 생성하도록 역할(Role), 기술 제약 조건, 입출력 포맷, 예외 처리 규칙을 정밀하게 설계하는 기법입니다.

컨텍스트 윈도우 (Context Window)

AI 작업 기억 한도

AI 모델이 단일 질의 및 대화에서 한 번에 참조할 수 있는 코드 및 텍스트의 총량입니다. Cursor의 @Files 등을 통해 필요한 파일만 효율적으로 주입해야 품질이 유지됩니다.

AI 래퍼 (AI Wrapper)

LLM API 특화 응용 소프트웨어

OpenAI, Anthropic 등의 기반 대형 언어 모델 API를 활용하여 특정 산업이나 타겟 직군의 문제 해결에 최적화된 프롬프트와 인터페이스를 결합한 SaaS 제품군입니다.

3. 웹 아키텍처 및 인프라 (Web & Infrastructure)

프론트엔드 / 백엔드 (Frontend & Backend)

클라이언트 영역 vs 서버 영역

프론트엔드는 사용자가 상호작용하는 UI 화면과 브라우저 인터페이스를 뜻하며, 백엔드는 데이터 처리, 비즈니스 로직 연산, 결제 승인 등을 담당하는 서버 영역입니다.

API (Application Programming Interface)

소프트웨어 통신 인터페이스

독립된 두 시스템(예: 내 웹사이트와 토스페이먼츠 서버)이 정해진 규격과 형식(JSON 등)에 맞추어 데이터를 요청하고 응답받을 수 있도록 규정한 통신 규약입니다.

웹훅 (Webhook)

이벤트 기반 역방향 알림 통신

특정 이벤트(예: 결제 완료, 가상계좌 입금)가 발생했을 때, 외부 서비스 제공자가 내 서버의 지정된 URL(엔드포인트)로 즉각 HTTP POST 요청을 보내 상태를 전달하는 구조입니다.

DNS 및 CNAME 레코드

도메인 네임 시스템과 별칭 매핑

문자 형태의 도메인(service.io)을 서버 IP 주소로 변환하는 시스템이며, CNAME은 특정 도메인을 Vercel 호스팅 주소(cname.vercel-dns.com)로 연결할 때 사용합니다.

4. 데이터베이스 및 보안 (Database & Security)

RLS (Row Level Security)

행 단위 접근 제어 보안 정책

데이터베이스의 레코드(행) 수준에서 접근 권한을 엄격하게 제한하는 보안 규칙입니다. 인증된 사용자 본인의 식별자(user_id)와 일치하는 데이터만 읽고 쓸 수 있도록 격리합니다.

환경변수 (Environment Variables, .env)

비공개 시스템 설정 값 격리

데이터베이스 비밀번호, PG사 시크릿 키 등 공개 저장소(Git)에 노출되어서는 안 되는 민감한 비밀값을 코드 외부의 격리된 환경 파일에 보관하고 서버에서만 참조하는 체계입니다.

5. 결제 및 전자상거래 규정 (Payments & Legal)

PG사 (Payment Gateway)

전자지급결제대행사

가맹점을 대신하여 다수의 카드사 및 간편결제사와 계약을 체결하고, 웹사이트에서 신용카드, 카카오페이 등의 결제가 안전하게 처리되도록 중개하는 기업입니다.

간이과세자

소규모 개인사업자 과세 특례

연간 공급대가(매출)가 1억 400만 원 미만인 소규모 개인사업자에게 적용되는 과세 유형으로, 일반과세자에 비해 부가가치세 납부 부담이 적고 세무 처리가 간소화됩니다.

통신판매업 신고

전자상거래 소비자보호법상 의무 신고

온라인에서 디지털 콘텐츠나 상품, 구독 서비스를 불특정 다수에게 유료로 판매하기 위해 관할 지방자치단체(정부24)에 등록해야 하는 법적 행정 절차입니다.

구매안전서비스 (에스크로)

소비자 결제대금 보호 제도

구매자가 제품을 정상 수령하거나 서비스를 개시하기 전까지 제3의 공신력 있는 기관이 결제 대금을 예치·보관하는 제도로, 통신판매업 신고 시 확인증 제출이 필수입니다.
