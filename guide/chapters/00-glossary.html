비개발자도 술술 읽히는 1인 창업 & 바이브코딩 핵심 개념 20선

책을 본격적으로 읽기 전, 본문에 자주 등장하는 알쏭달쏭한 IT·비즈니스 용어들을 초등학생도 이해할 수 있는 쉬운 비유로 모았습니다. 딱 3분만 훑어보시면 가이드북의 모든 내용이 2배로 쉽게 읽힙니다!

💼 1. 비즈니스 & 린 스타트업 핵심 용어

🛹 MVP (Minimum Viable Product)

최소 기능 제품

아이디어가 돈이 되는지 검증하기 위해, 부가 기능을 다 빼고 '핵심 기능 1개'만 넣어 7일 안에 던져보는 시제품 (스케이트보드 비유).

🎯 PMF (Product-Market Fit)

제품-시장 적합성

내가 만든 제품이 시장의 절실한 문제와 완벽히 맞아떨어져, 억지로 광고하지 않아도 고객들이 알아서 지갑을 열고 입소문을 내는 마법의 순간.

☁️ SaaS (Software as a Service)

서비스형 소프트웨어

컴퓨터에 무겁게 설치할 필요 없이 웹 브라우저에서 바로 로그인해서 쓰고, 매달 구독료나 사용량만큼 돈을 내는 클라우드 소프트웨어 (예: 노션, 슬랙).

🏃 스프린트 (Sprint)

단기 단거리 전력 질주

몇 달씩 늘어지는 프로젝트 대신, 7일(또는 14일) 동안 목표를 명확히 정하고 전속력으로 하나의 배포 버전을 만들어내는 개발 주기.

🤖 2. 바이브코딩 & AI 핵심 용어

✨ 바이브 코딩 (Vibe Coding)

느낌과 맥락 중심의 AI 페어 프로그래밍

문법이나 세미콜론을 외우는 대신, 원하는 서비스의 기획과 느낌(Vibe)을 AI에게 자연어로 지시하여 고품질 코드를 생성해내는 새로운 개발 패러다임.

💬 프롬프트 (Prompt)

AI에게 내리는 지시문

AI에게 "버튼 만들어줘" 대신 "역할, 기술 스택, 디자인 토큰, 예외 처리"를 명확히 지정해 실패 없는 코드를 뽑아내는 업무 지시서.

🧠 컨텍스트 (Context)

AI의 작업 기억 용량

AI가 현재 대화에서 기억하고 있는 프로젝트 파일들과 이전 대화의 총량. Cursor의 @Docs나 @Files로 AI에게 필요한 파일만 콕 집어 전달합니다.

🎁 AI 래퍼 (AI Wrapper)

LLM API 기반 특화 서비스

ChatGPT나 Claude 같은 거대 AI 모델의 API를 가져와, 특정 타겟(예: 부동산 매물 카피, 이력서 첨삭 등)에 딱 맞는 맞춤형 UI로 포장해 판매하는 SaaS.

🌐 3. 웹 기술 & 인프라 핵심 용어

🍽️ 프론트엔드 vs 백엔드

식당 홀 vs 주방

프론트엔드는 손님이 보는 인테리어와 메뉴판(화면, 버튼, 디자인), 백엔드는 보이지 않는 곳에서 요리를 만들고 재료를 꺼내오는 주방(데이터베이스, 결제 검증).

🔌 API (Application Programming Interface)

서로 다른 프로그램 간의 공식 대화창구

내 웹사이트가 토스페이먼츠에게 "이 유저 1만 원 결제 승인해줘"라고 요청서를 보내고 답변을 받는 정해진 통신 규칙/규격.

🔔 웹훅 (Webhook)

서버 간 역방향 실시간 알림

내가 계속 "결제됐나요?" 물어보지 않아도, 토스 서버에서 결제가 성공하는 즉시 내 서버 주소로 "돈 들어왔으니 이용권 열어줘!" 하고 찔러주는 자동 배달원.

🌐 DNS & CNAME

인터넷 전화번호부 & 별명

복잡한 컴퓨터 IP 주소(76.76.21.21) 대신 사람들이 기억하기 쉬운 도메인 이름(mybrand.io)을 Vercel 서버로 연결해 주는 인터넷 이정표.

🔒 4. 데이터베이스 & 보안 핵심 용어

🛡️ RLS (Row Level Security)

행(데이터 1줄) 단위 보안 자물쇠

Supabase의 핵심 보안 기술. "A 유저는 오직 자기 user_id가 적힌 데이터만 읽고 쓸 수 있다"는 규칙을 걸어 타인의 개인정보 유출을 원천 차단합니다.

🔐 환경변수 (.env)

금고 비밀번호 모음집

코드 파일에 직접 적으면 안 되는 토스 비밀 키, DB 마스터 패스워드 등을 따로 숨겨두는 비공개 설정 파일 (절대 GitHub에 올리면 안 됨!).

💳 5. 결제 & 창업 법률 핵심 용어

🏦 PG사 (Payment Gateway)

전자 결제 대행사

내가 신한, 삼성, 국민 등 수십 개 카드사를 일일이 찾아가지 않아도, 대신 카드사 승인을 받아주고 결제창을 띄워주는 회사 (토스페이먼츠, 이니시스 등).

🔰 간이과세자

초기 1인 창업자용 세금 감면 혜택

연 매출 1억 400만 원 미만의 소규모 개인사업자에게 부가가치세를 대폭 깎아주거나 면제해 주는 대한민국 세법상의 혜택 제도.

📜 통신판매업 신고

인터넷 쇼핑몰/SaaS 합법 운영 허가증

온라인에서 불특정 다수에게 유료 결제를 받으려면 정부24에 의무적으로 신고해야 하는 법적 서류 (미신고 시 과태료 발생).

🤝 구매안전서비스 (에스크로)

소비자 보호용 결제 보관 장치

소비자가 물건을 받기 전까지 결제 대금을 제3자(은행/PG사)가 안전하게 보관하는 제도. 통신판매업 신고 시 이 확인증이 반드시 첨부되어야 합니다.
