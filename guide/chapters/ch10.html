Day 6-7: Vercel 배포 &
도메인 연결 완전 정복

⏱ 약 5분·PART 3 · 실행

코드는 완성됐습니다. 이제 전 세계 누구나 접속할 수 있도록 인터넷에 올릴 차례입니다. Vercel은 코드를 GitHub에 올리면 버튼 하나로 전 세계 배포가 완료되는 마법 같은 도구입니다.

Vercel 배포 5단계 (클릭 5번으로 끝납니다)

1
GitHub에 최종 코드 push
→
2
vercel.com 에서 GitHub 레포 Import
→
3
환경변수 (Env Variables) 설정
→
4
Deploy → 자동 HTTPS 도메인 발급
→
5
커스텀 도메인 연결 (선택) → DNS A 레코드 설정

🚨 배포 실패의 90%는 이 2가지입니다

01
환경변수 누락 — "로컬에서 되는데 Vercel에서 안 돼요"의 원인 1위

로컬 개발 시 .env.local에 저장했던 모든 환경변수(NEXT_PUBLIC_SUPABASE_URL, TOSS_SECRET_KEY 등)를 Vercel 대시보드 → [Settings] → [Environment Variables]에 하나씩 동일하게 입력해야 합니다. 하나라도 빠지면 흰 화면 또는 500 에러가 납니다.

02
TypeScript 타입 에러 — 로컬에서 무시하고 지나친 에러가 빌드를 막습니다

개발 중 any로 임시 처리하거나 타입 에러를 무시한 코드가 Vercel의 엄격한 빌드 환경에서 걸립니다. 빌드 로그의 빨간 줄을 아래 PROMPT #8에 그대로 복사하면 Cursor가 즉시 수정해 줍니다.

💡
Vercel 무료 플랜으로 몇 명까지 수용 가능할까요?
개인 프로젝트 기준 월 100GB 대역폭과 서버리스 함수 실행 100시간이 무료입니다. 초기 유료 고객 약 1,000~2,000명까지는 무료로 충분히 감당합니다. 그 이후 유료 전환은 월 $20 (Pro 플랜)입니다. 고객 1,000명이 생겼다면 이미 성공한 것이니 기쁘게 올리면 됩니다.
