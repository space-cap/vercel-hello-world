Step 2. 가비아(Gabia) 도메인 Vercel 3분 연결 가이드

`my-mvp.vercel.app` 같은 임시 주소 대신, 신뢰도를 위해 내 전용 도메인(`www.mymvp.com`)을 연결하는 실전 순서입니다.

01
Vercel 대시보드에 도메인 추가

Vercel 프로젝트 대시보드 → [Settings] → [Domains] 메뉴로 이동합니다. 구입한 도메인(예: mymvp.com)을 입력하고 [Add]를 누릅니다. Vercel이 www.mymvp.com도 함께 등록할지 물어보면 [Recommended] 옵션을 선택합니다.

02
가비아 DNS 관리툴 접속

가비아(gabia.com) 로그인 → [My가비아] → 내 도메인의 [관리] 클릭 → [DNS 설정] → [설정] 버튼을 누릅니다.

03
DNS 레코드 2줄 등록 (딱 2줄만 넣으면 끝납니다)
타입호스트값/위치 (Vercel 타겟)TTL
A @ 76.76.21.21 3600 (기본)
CNAME www cname.vercel-dns.com. 3600 (기본)
04
Vercel 확인 & 자동 SSL 발급 대기 (약 3~5분)

Vercel 화면으로 돌아와 [Refresh]를 누르면 파란색 체크 표시와 함께 Valid Configuration이 뜨며 무료 SSL 보안인증서(HTTPS 자물쇠)가 100% 자동 발급됩니다.

💡
도메인 연결 시 주의할 점:
DNS 설정 후 전 세계 서버로 정보가 전파되는 데 보통 5분~최대 1시간 정도 걸립니다. 설정 직후 접속이 안 된다고 레코드를 마구 지우지 마시고, 10분 정도 여유를 두고 스마트폰 LTE로 접속해 보세요.

🚨 배포 실패의 90%는 이 2가지입니다

01
환경변수 누락 — "로컬에서 되는데 Vercel에서 안 돼요"의 원인 1위

로컬 개발 시 .env.local에 저장했던 모든 환경변수(NEXT_PUBLIC_SUPABASE_URL, TOSS_SECRET_KEY 등)를 Vercel 대시보드 → [Settings] → [Environment Variables]에 하나씩 동일하게 입력해야 합니다. 하나라도 빠지면 흰 화면 또는 500 에러가 납니다.

02
TypeScript 타입 에러 — 로컬에서 무시하고 지나친 에러가 빌드를 막습니다

개발 중 any로 임시 처리하거나 타입 에러를 무시한 코드가 Vercel의 엄격한 빌드 환경에서 걸립니다. 빌드 로그의 빨간 줄을 아래 PROMPT #8에 그대로 복사하면 Cursor가 즉시 수정해 줍니다.
