Day 1: Cursor 세팅과
첫 컴포넌트 바이브코딩

⏱ 약 6분·PART 3 · 실행

Cursor는 AI가 개발자의 손과 눈이 되어 코드를 직접 작성하고 수정하는 차세대 에디터입니다. Visual Studio Code에 초지능 AI 두뇌를 이식한 것이라고 이해하시면 됩니다.

Day 1 세팅 6단계 체크리스트

⚡ 비개발자 70%가 포기하는 '검은 화면(터미널) 공포증' 극복 3대 치트키

바이브코딩을 시작할 때 비개발자가 가장 얼어붙는 순간은 "명령어를 쳤더니 터미널에 시뻘건 영어 에러 메시지가 쏟아질 때"입니다. 아래 3가지만 알면 터미널은 두려움의 대상이 아니라 마법의 지팡이가 됩니다.

01
터미널 열기 단축키는 단 하나: Ctrl + ` (맥: Cmd + `)

복잡한 윈도우 파워쉘이나 CMD를 따로 켤 필요가 없습니다. Cursor 안에서 백틱(키보드 1번 좌측 물결 키)을 누르면 아래쪽에 터미널이 마법처럼 나타납니다.

02
"빨간 에러 메시지 = AI에게 줄 최고의 먹이"

에러는 대표님이 잘못해서 나는 게 아닙니다. 라이브러리 버전이 안 맞거나 오타가 난 것뿐입니다. 당황해서 창을 끄지 마시고, 빨간 줄 전체를 마우스로 긁어서 복사(Ctrl+C)하세요.

03
Cursor 채팅창(Ctrl + L)에 던지면 3초 만에 해결책을 줍니다

복사한 빨간 줄을 Cursor Chat에 넣고 "이 에러가 왜 났는지 한국어로 알려주고, 터미널에 칠 해결 명령어 1줄만 줘"라고 하면 99.9% 단번에 해결됩니다.
