APPENDIX F
🚀 D-Day 런칭 직전 파이널 체크리스트 30선
오픈 당일 식은땀 흘리지 않는 1인 창업 MVP 최종 검증 표

드디어 서비스를 세상에 선보이는 날입니다! 흥분되는 순간이지만, 사소한 설정 누락 하나로 결제가 실패하거나 고객이 이탈할 수 있습니다. 프로덕트 헌트, 디스콰이엇, 오픈채팅방에 링크를 뿌리기 전, 아래 30가지 항목을 하나씩 체크하며 안전하게 이륙하세요.

1. 🔒 보안 & 인프라 환경설정 (6문항)

상태 검증 항목 상세 점검 내용
.gitignore 환경변수 격리 .env.local 및 비공개 키가 GitHub 공개 레포에 올라가지 않았는지 확인
Vercel 환경변수 등록 Production 환경변수에 Supabase, Toss, Resend의 실서버 키가 모두 등록되었는지 확인
Supabase RLS 활성화 모든 테이블에 Row Level Security(RLS)가 켜져 있어 타인의 데이터 조회가 차단되는지 확인
HTTPS 보안 인증서 커스텀 도메인 접속 시 브라우저 주소창에 자물쇠(SSL)가 정상 표기되는지 확인
관리자 페이지 권한 격리 /admin 등 대시보드 URL에 일반 유저가 접근할 수 없는지 검증
API Rate Limiting 악의적 매크로 호출로 인한 서버/AI 과금 폭탄 방지책(호출 제한) 적용 여부

2. 💳 결제 & 유료 과금 흐름 (6문항)

상태 검증 항목 상세 점검 내용
토스페이먼츠 라이브 키 전환 테스트 키(test_ck_...)에서 운영 승인된 라이브 키(live_ck_...)로 교체 완료
100원 실결제 테스트 실제 본인 카드로 결제 후 승인, 데이터베이스 권한 부여까지 정상 작동하는지 확인
결제 취소/환불 테스트 상점 관리자에서 100원 결제 건 즉시 취소 후 환불 처리가 정상 완료되는지 확인
결제 실패 예외 처리 한도 초과, 잔액 부족 시 사용자에게 친절한 에러 안내 모달이 뜨는지 확인
결제 완료 이메일 영수증 결제 즉시 유저 이메일로 이용권 발급 및 영수증 안내 메일(Resend)이 오는지 확인
가격 표기 통일 랜딩페이지의 가격과 실제 결제 팝업에 뜨는 금액(부가세 포함 여부)이 일치하는지 확인

3. ⚖️ 법적 표시 & 고객 지원 (6문항)

상태 검증 항목 상세 점검 내용
하단 사업자 7대 정보 상호명, 대표자명, 사업자번호, 통신판매번호, 주소, 연락처, 개인정보책임자 텍스트 표기
이용약관 링크 작동 푸터의 /terms 링크 클릭 시 공정위 표준 이용약관이 정상 렌더링되는지 확인
개인정보처리방침 링크 작동 푸터의 /privacy 링크 클릭 시 수집 항목 및 파기 절차가 명시되어 있는지 확인
디지털 콘텐츠 환불 제한 고지 결제 화면에 "이용 개시 후 단순 변심 환불 제한" 사전 동의 문구 명시 여부
1:1 문의 채널 연결 채널톡, 카카오톡 채널 또는 지원 이메일(support@...) 링크가 정상 작동하는지 확인
회원 탈퇴 기능 법적으로 유저가 본인 계정을 직접 탈퇴/삭제할 수 있는 기능 구비 여부

4. 🌐 SEO & SNS 공유 최적화 (6문항)

상태 검증 항목 상세 점검 내용
카카오톡/슬랙 OG 썸네일 링크를 카톡/슬랙에 전송했을 때 매력적인 제목, 설명, 썸네일 이미지(1200x630)가 뜨는지 확인
브라우저 파비콘(Favicon) 탭 상단에 기본 Next.js/Vercel 로고가 아닌 내 서비스의 브랜드 아이콘이 뜨는지 확인
페이지 메타 타이틀/설명 구글 검색 결과에 노출될 명확한 한 줄 가치 제안 메타 태그 입력 여부
robots.txt & sitemap.xml 검색 로봇(Googlebot, Naver Yeti)이 페이지를 수집할 수 있도록 정상 제공되는지 확인
Vercel / GA4 분석 도구 방문자 수, 유입 경로, 버튼 클릭 수를 추적할 트래커 스크립트 연동 확인
도메인 www / non-www 리다이렉트 www.mydomain.com과 mydomain.com 모두 단일 주소로 일관되게 이동하는지 확인

5. 📱 모바일 UX & 크로스 브라우징 (6문항)

상태 검증 항목 상세 점검 내용
아이폰 사파리(Safari) 뷰포트 하단 브라우저 바에 메인 CTA 버튼이 가려지지 않는지 확인 (100dvh 적용)
모바일 인풋 확대 방지 아이폰에서 인풋창 터치 시 화면이 멋대로 줌인되지 않도록 font-size: 16px 이상 유지
404 Not Found 페이지 디자인 엉뚱한 URL 입력 시 기본 서버 에러 대신 홈으로 돌아가는 친절한 404 페이지 노출 여부
로딩 스피너 및 빈 상태(Empty State) 데이터를 불러올 때 화면이 멈춘 것처럼 보이지 않고 로딩 표시가 뜨는지 확인
폼 유효성 검사 안내 이메일 형식 오류, 비밀번호 불일치 시 사용자에게 붉은 안내 텍스트가 명확히 나오는지 확인
다크모드 글자 대비 다크모드 지원 시 배경색과 텍스트의 대비가 충분하여 글자가 묻히지 않는지 확인
