APPENDIX E
내 MVP에 AI 기능 붙이기 (LLM 연동 & 크레딧 과금 설계)
OpenAI / Claude API 스트리밍 연동과 유저별 크레딧 차감 완벽 구현

현재 1인 창업 시장에서 가장 빠르게 수익화에 성공하는 비즈니스 모델은 바로 '특정 분야 특화 AI 래퍼(AI Wrapper) SaaS'입니다. 거창한 자체 AI 모델을 훈련할 필요 없이, OpenAI나 Claude의 API를 가져와 직관적인 UI와 맞춤형 프롬프트로 포장하면 훌륭한 유료 서비스가 됩니다. API 보안 격리부터 부드러운 스트리밍 출력, 그리고 크레딧 과금 로직까지 실전 레시피를 공개합니다.

1. AI 래퍼 SaaS의 수익 구조와 아키텍처

① 맞춤형 인풋 폼

사용자에게 일반 챗봇 대신, '목적에 맞는 직관적인 입력창(예: 업종, 타겟층, 상품 특징)'을 제공합니다.

② 서버 시크릿 프롬프트 결합

클라이언트가 모르는 백엔드 비밀 시스템 프롬프트를 덧붙여 고품질 결과물을 생성합니다.

③ 크레딧 차감 & 마진 확보

API 원가(건당 약 1~5원) 대비 사용자에게는 크레딧 결제(건당 100~300원 가치)를 유도하여 90% 이상의 영업이익률을 확보합니다.

2. 보안 필수: Route Handler 서버 격리 (`/api/generate`)

AI API 키(OPENAI_API_KEY, ANTHROPIC_API_KEY)를 리액트 클라이언트 컴포넌트나 브라우저에 직접 노출하면 악의적인 유저가 키를 탈취해 수백만 원의 요금 폭탄을 맞을 수 있습니다. 반드시 서버 사이드 Route Handler를 통해서만 호출해야 합니다.

💻 서버 사이드 스트리밍 엔드포인트 예시 (Next.js App Router)
// app/api/ai/generate/route.ts import { NextResponse } from 'next/server'; import { createClient } from '@/utils/supabase/server'; export async function POST(req: Request) { const supabase = createClient(); // 1. 유저 인증 확인 const { data: { user } } = await supabase.auth.getUser(); if (!user) { return NextResponse.json({ error: '로그인이 필요합니다.' }, { status: 401 }); } // 2. 유저 크레딧 잔여량 확인 const { data: profile } = await supabase .from('profiles') .select('credits') .eq('id', user.id) .single(); if (!profile || profile.credits < 1) { return NextResponse.json({ error: '크레딧이 부족합니다. 충전 후 이용해주세요.' }, { status: 402 }); } // 3. 크레딧 1 차감 (트랜잭션) await supabase .from('profiles') .update({ credits: profile.credits - 1 }) .eq('id', user.id); // 4. OpenAI / Anthropic API 호출 (서버 전용 환경변수 사용) const { prompt } = await req.json(); const res = await fetch('https://api.openai.com/v1/chat/completions', { method: 'POST', headers: { 'Authorization': `Bearer ${process.env.OPENAI_API_KEY}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ model: 'gpt-4o-mini', // 비용이 매우 저렴한 모델 권장 messages: [ { role: 'system', content: '당신은 상위 1% 전문 마케팅 카피라이터입니다.' }, { role: 'user', content: prompt } ], stream: true }) }); return new Response(res.body, { headers: { 'Content-Type': 'text/event-stream' } }); }

3. Vercel AI SDK로 타자 치듯 부드러운 스트리밍 UI

Vercel 공식 패키지인 npm i ai @ai-sdk/openai를 사용하면 복잡한 웹소켓이나 SSE 처리 없이 단 몇 줄로 실시간 타자 애니메이션 UI를 구현할 수 있습니다.

💻 프론트엔드 실시간 AI 스트리밍 폼 (Client Component)
'use client'; import { useCompletion } from 'ai/react'; export default function AIGenerator() { const { completion, input, handleInputChange, handleSubmit, isLoading } = useCompletion({ api: '/api/ai/generate', }); return ( <div className="max-w-xl mx-auto p-6"> <form onSubmit={handleSubmit} className="space-y-4"> <textarea value={input} onChange={handleInputChange} placeholder="아이디어를 입력하면 매력적인 카피를 뽑아드립니다..." className="w-full p-3 border rounded-lg" rows={3} /> <button type="submit" disabled={isLoading} className="w-full py-3 bg-blue-600 text-white font-bold rounded-lg hover:bg-blue-700" > {isLoading ? '생각하는 중...' : '✨ 1크레딧으로 AI 생성하기'} </button> </form> {completion && ( <div className="mt-6 p-4 bg-gray-50 border rounded-lg whitespace-pre-wrap"> <h4 className="font-bold text-gray-800 mb-2">생성 결과:</h4> {completion} </div> )} </div> ); }

4. Cursor에 한 번에 시키는 실전 복붙 프롬프트

🤖 Cursor Composer (Ctrl+I) 전용 복붙 프롬프트
우리 Next.js 15 App Router 프로젝트에 AI 생성 기능과 크레딧 차감 시스템을 구축해줘: 1. Supabase profiles 테이블에 `credits INTEGER DEFAULT 5` 컬럼이 연동되어 있다고 가정. 2. `/app/api/ai/generate/route.ts`에 Route Handler를 만들어줘: - Supabase 세션 체크 (미로그인 시 401) - 크레딧 잔여량 확인 (1 미만 시 402 에러 반환) - 크레딧 1 차감 업데이트 - OpenAI API를 호출하여 스트리밍(Streaming)으로 응답 반환 3. 프론트엔드 컴포넌트(`components/AICreator.tsx`)를 만들어줘: - 잔여 크레딧 뱃지 표시 - 인풋 폼과 실시간 타자 스트리밍 결과창 - 크레딧이 0일 때 '충전하기(/pricing)' 모달을 띄우는 안내 로직 포함
💰 비용 절감 팁: 저렴한 고성능 모델 선택

초기 MVP에서는 건당 비용이 매우 저렴한 gpt-4o-mini(입력 $0.15/1M, 출력 $0.60/1M 토큰) 또는 Anthropic의 claude-3-5-haiku 모델을 기본 모델로 세팅하세요. 100회 생성 시 실제 서버 비용은 50원 미만으로 수렴합니다.
