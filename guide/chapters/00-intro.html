이 책은 처음부터 끝까지 순서대로 읽도록 설계되었습니다. 각 파트는 이전 파트의 내용을 기반으로 쌓이며, 마지막 챕터를 읽을 때쯤이면 여러분은 실제 수익이 나는 제품의 초안을 손에 쥐게 됩니다.

30-SECOND DEFINITION

바이브코딩(Vibe Coding)이란 무엇인가?

"내가 만들고 싶은 것을 한국어로 말하면, AI가 코드를 짜주는 개발 방식."
프로그래밍 언어를 배울 필요가 없습니다. Python, JavaScript, SQL을 몰라도 됩니다. 대신 "사용자가 이메일을 입력하고 결제 버튼을 누르면 Supabase에 주문이 저장되고, 토스로 결제창이 열려야 해"처럼 비즈니스 로직을 말로 설명하면, Cursor나 Claude 같은 AI가 작동하는 코드를 만들어냅니다.

❌ 기존 개발 방식
  • 코딩 언어 6개월 독학
  • 외주사에 3,000만 원 의뢰
  • 6개월 뒤 MVP 런칭
  • 유지보수비 월 30만 원 지속 납부
✅ 바이브코딩 방식
  • AI에게 원하는 기능 한국어로 설명
  • 직접 Cursor로 7일 만에 구현
  • 토스 결제 즉시 연동, 라이브 런칭
  • 이후 유지보수도 AI와 단둘이 해결
💡
읽기 방법 제안
각 챕터 말미에 실습 워크시트가 있습니다. 단순히 읽고 지나치지 말고, 반드시 자신의 아이디어를 적용해보세요. 생각을 글로 옮기는 순간 아이디어가 계획이 됩니다.

또한 프롬프트 박스가 나올 때마다 우측 상단의 [복사] 버튼을 눌러 Claude, ChatGPT, 또는 Cursor의 채팅창에 바로 붙여넣어 보세요. 이 책의 프롬프트는 모두 실전에서 검증된 완성형입니다.

⚠️
이 책이 알려주지 않는 것
파이썬 문법, HTML 태그 의미, CSS 속성값. 이 책은 코딩을 가르치지 않습니다. 대신 코딩을 AI에게 위임하고, 비즈니스에 집중하는 법을 알려줍니다.
