Day 5: 토스페이먼츠 결제 연동 —
첫 1,000원의 전율과 실전 심사·보안 가이드

⏱ 약 8분·PART 3 · 실행

내 웹사이트에서 첫 결제가 실제로 터지는 순간은 창업가 인생에서 잊지 못할 희열을 줍니다. "단순한 코드 덩어리"가 "고객이 신용카드를 꺼내 돈을 지불하는 진짜 비즈니스"로 승격되는 날이기 때문입니다.

Step 1. 토스페이먼츠 3단계 연동 흐름

01
토스 개발자센터 가입 & 테스트 API 키 발급

developers.tosspayments.com 에서 무료 가입 후 [내 개발 정보]에서 테스트 클라이언트 키(`test_ck_...`)와 시크릿 키(`test_sk_...`)를 복사해 프로젝트의 .env.local에 저장합니다.

02
결제창 SDK 호출 (프론트엔드 UI)

Cursor에게 아래 PROMPT #7을 주면 결제창 위젯 컴포넌트를 즉시 생성해 줍니다. 고객이 [결제하기]를 누르면 카카오페이, 토스페이, 신용카드 창이 뜹니다.

03
결제 승인 API (서버 사이드 백엔드)

고객이 결제를 마쳤다고 끝이 아닙니다. 백엔드 서버가 토스 승인 API를 호출하여 "위변조가 없는 진짜 결제인가?" 최종 검증한 뒤 Supabase DB에 주문 완료 상태(`PAID`)를 기록해야 합니다.

📋 PROMPT #7 — 토스페이먼츠 결제창 v2 및 백엔드 승인 API 완성본 
Next.js 15 App Router와 토스페이먼츠 최신 SDK를 연동해 주세요.

결제 흐름:
1. 사용자가 상품 결제 버튼 클릭 (/pricing 또는 /checkout)
2. 토스페이먼츠 결제창 오픈 (금액: [금액]원, 주문명: [주문명])
3. 결제 인증 성공 시 /payment/success 로 리다이렉트 (orderId, paymentKey, amount 파라미터 전달)
4. /payment/success 페이지에서 백엔드 승인 API(/api/payment/confirm) POST 요청
5. 승인 완료 시 Supabase orders 테이블에 status='PAID' 저장 및 유저 서비스 이용 권한 부여

필수 보안 조건:
- TOSS_SECRET_KEY는 오직 백엔드 API route(서버 사이드)에서만 사용해야 하며, 클라이언트에 절대 노출되지 않도록 할 것.
- 결제 요청 금액과 실제 승인 금액이 일치하는지 서버에서 교차 검증할 것.
- 이미 승인된 orderId가 중복 요청되었을 때 멱등성(Idempotency) 방어 로직을 작성할 것.

작성할 파일 목록:
- components/PaymentCheckout.tsx
- app/payment/success/page.tsx
- app/api/payment/confirm/route.ts

Step 2. 99% 반려 방지: 토스페이먼츠 비대면 심사 통과 체크리스트

테스트 모드에서 결제가 잘 되더라도, 실제 돈을 받으려면 토스페이먼츠의 가맹점 심사를 받아야 합니다. 아래 5가지가 웹사이트에 없으면 심사가 100% 반려됩니다.

Step 3. 테스트 모드 ➔ 실제 돈 들어오는 '라이브 모드' 전환 4단계

심사가 승인되면 [토스페이먼츠 상점관리자]에서 실운영 키(`live_ck_...`, `live_sk_...`)를 발급받을 수 있습니다.

01
Vercel 환경변수(Environment Variables) 교체

Vercel 대시보드 → 프로젝트 Settings → [Environment Variables]에서 `NEXT_PUBLIC_TOSS_CLIENT_KEY`와 `TOSS_SECRET_KEY` 값을 `live_`로 시작하는 실운영 키로 교체합니다.

02
Vercel 재배포(Redeploy) 실행

환경변수를 바꾼 뒤에는 반드시 Vercel [Deployments]에서 최신 배포본의 [...] 메뉴를 눌러 [Redeploy]를 실행해야 새 키가 서버에 적용됩니다.

03
내 신용카드로 1,000원 테스트 결제 & 취소

라이브 사이트에서 본인의 카드로 직접 1,000원을 결제해 보세요. 통장에서 돈이 빠져나가고, 사이트 권한이 부여되고, 토스 상점관리자에 결제 내역이 뜨면 즉시 [취소] 버튼을 눌러 환불을 확인합니다.

04
웹훅(Webhook) 실시간 알림 등록

토스 개발자센터 → [웹훅 관리]에서 `https://내도메인.com/api/payment/webhook`을 등록하면 가상계좌 입금이나 카드 취소 건도 자동으로 DB와 동기화됩니다.

⚠️ 비개발자가 결제 연동 시 저지르는 2대 치명적 실수

🚨
실수 1: 시크릿 키(Secret Key) 클라이언트 노출
NEXT_PUBLIC_ 접두사를 시크릿 키 앞에 붙이면 웹 브라우저의 [개발자 도구]에서 누구나 대표님의 결제 비밀키를 볼 수 있게 됩니다. 결제 취소나 무단 승인 등 금전적 사고로 이어지므로, 시크릿 키는 반드시 접두사 없는 순수 환경변수로 백엔드에서만 불러와야 합니다.

실수 2: 클라이언트 금액 변조(F12 조작) 공격 방어 누락
악의적인 사용자가 개발자 도구에서 10,000원짜리 결제 금액을 100원으로 변조해 결제할 수 있습니다. 반드시 백엔드 승인 API에서 "원래 DB에 저장된 주문 금액과 토스가 승인한 금액이 정확히 일치하는지" 대조해야 합니다.
